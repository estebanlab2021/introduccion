Material and methods

Data Preprocessing and Modeling Strategy

To evaluate the sexual dimorphism of the three cuneiform bones, incomplete cases with missing values (NA) were removed, leaving 167 adult individuals (100 males, 67 females). To prevent class imbalance from biasing the logistic regression models toward the majority class, random undersampling of the male group was conducted, yielding a balanced dataset of N = 134 individuals (67 males, 67 females). All predictor variables were standardized using z-score transformation (x_scaled = (x - mean(x)) / sd(x),) based on the training set parameters to maintain identical scale contributions across variables. The balanced dataset was partitioned into a training set (70%, n = 94) and an independent test set (30%, n = 40). On the training set, binary logistic regression models were fitted using k-fold cross-validation (k = 10) to mitigate overfitting and ensure robust hyperparameter tuning. Model optimization and variable selection were guided by backward stepwise elimination based on the Akaike Information Criterion (AIC). Complete models (utilizing all 17 measurements) and reduced, bone-specific models (Medial, Intermediate, and Lateral) were fitted separately. Final predictive performance was evaluated on the unseen test set (n = 40) using a classification threshold of p = 0.5, reporting Accuracy, Sensitivity, Specificity, AIC, and Receiver Operating Characteristic–Area Under the Curve (ROC-AUC). While advanced machine learning classifiers were considered, logistic regression was selected as a suitable baseline model given the sample size constraints, with future expansions planned as sample sizes increase. Statistical analyses and modeling were performed in R (v4.4.0) using dplyr for data manipulation, caret for dataset partitioning and cross-validation, and pROC alongside ROCR for ROC curve and AUC evaluation.
